# Credits

## Lava surface reference

The animated lava material in `shaders/lava.gdshader` is an original lightweight
Godot shader written for this project. Its moving-surface direction was inspired
by the ocean-wave presentation in [godot-ocean-waves-buoyancy by ManickYoj](https://github.com/ManickYoj/godot-ocean-waves-buoyancy).

No code or assets from that repository are bundled here. Please see that project's
repository for its own authorship and license information.
